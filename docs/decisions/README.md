# Decisions

One file per decision that a reader of the code would otherwise have to guess at: the context, the options that were
really on the table, what was chosen, and what it costs. Short is fine; the reasoning is the point.

Write one when a choice is hard to reverse, surprising, or was argued about. The design of record is
[`../design/fleet-v2-architecture.md`](../design/fleet-v2-architecture.md) — an ADR explains a decision the design does
not, it does not restate it.
